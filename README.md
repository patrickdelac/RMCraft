# RMCraft

RMCraft is a web-based README generator that helps you create a clear, polished README for a project. Add your project details and see the formatted Markdown update live, then copy it or download it as `README.md`.

## Features

- Add project details, a demo URL, technology badges, features, installation steps, author information, and a license.
- Preview the generated README as formatted Markdown while editing.
- Copy the Markdown to your clipboard or download it as a file.
- Choose light or dark mode; your theme preference is saved in the browser.

## Tech Stack

- Next.js and React
- TypeScript
- Custom CSS
- `react-markdown` and `remark-gfm` for rendering Markdown

## Run Locally

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

To create and run a production build:

```bash
npm run build
npm start
```
